# Urenregistratie Paneelbouw
Offline HTML-app voor urenregistratie.

Bestanden:
- index.html
- style.css
- app.js
- manifest.json
- sw.js

Gegevens worden lokaal in de browser opgeslagen. De app bevat projectbeheer, project verwijderen, registratie verwijderen/bewerken, timer, handmatige uren, notities, dag/week/maand, print en JSON-export.
